# 🔐 Login com Validação de Formulário

Projeto desenvolvido durante um desafio da **DIO**, com o objetivo de praticar criação de formulários em React utilizando validações e controle de estado.

## 🚀 Demonstração

Acesse o projeto online:

🔗 https://MarcelleNascimento.github.io/botao-desabilitado

## 📌 Funcionalidades

* Tela de login com campos de e-mail e senha.
* Validação dos campos utilizando **React Hook Form** e **Yup**.
* Validação de e-mail com formato correto.
* Validação de senha com mínimo de 6 caracteres.
* Exibição de mensagens de erro nos campos inválidos.
* Controle do estado do formulário utilizando `isValid`.
* Botão "Entrar" desabilitado enquanto o formulário estiver inválido.
* Alteração visual do botão quando está desabilitado.

## 🛠️ Tecnologias utilizadas

* React
* TypeScript
* React Hook Form
* Yup
* Styled Components
